# Changelog

## 0.1.1

- Each version now previews the whole run you typed, not only the last key.
- Branches open by themselves, so the versions plain undo would lose are in view.
- Demo in the README.

## 0.1.0

First release. Every version of a file kept as a tree, a view to go back to any of them or compare it with now, Earlier and Later in time across branches, native undo and redo followed, saved versions marked, and an optional history that survives a restart.
